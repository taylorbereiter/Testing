# h-mart-voxel

A voxel replica of an H Mart, as a small tribute to *Crying in H Mart* by
Michelle Zauner — complete with the red wordmark and green sprout, glass
storefront, grocery aisles, a banchan/kimchi fridge wall, produce tables,
checkout lanes, shopping carts, a parking lot, and (of course) the food
court tucked into the back-right corner.

## Run

Open `index.html` in a browser (it loads Three.js from a CDN, so it needs
internet access). Or serve it locally:

```
cd projects/h-mart-voxel
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Controls

- Drag to orbit, scroll/pinch to zoom
- Press **R** (or tap the button) to lift the roof and peek inside
